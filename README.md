# WPlayer

An Android local media player


## Introduction

This is an Android local media player project,
it's still developing,
and it will implement more features in the future
> Note: Not yet ready for daily use and exists lots of bugs!

## Features

1. Play local audios
2. More features in development ...

## Quick start


### Environment

- Android SDK >= 24 
- Compile target SDK: 37
- JDK 17 (required by gradle)

### Build from source
```bash
git clone https://github.com/Winter-38/WPlayer.git
cd WPlayer
./gradlew assembleRelease 
```
